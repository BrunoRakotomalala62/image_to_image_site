Testez la transformation "Changer en bleue le vêtement"

Mode de fonctionnement

Cette démo simule la transformation d'image. Pour utiliser les vraies API Seedance/Seedream, vous devez intégrer vos clés API selon les instructions dans js/api-integration-example.js

La simulation appliquera un filtre bleu aux zones claires de l'image (simulant le changement de couleur du vêtement).

Conseils pour de meilleurs résultats

Pour le prompt "Changer en bleue le vêtement" :
• Utilisez une image avec un vêtement clairement visible
• Assurez-vous que le vêtement soit bien éclairé
• Seedream v4.5 donnera des résultats plus détaillés
• Une force de 0.7-0.9 est recommandée pour ce type de transformation
