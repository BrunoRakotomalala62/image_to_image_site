Comment tester vous-même

Option 1 : Page de test interactive

1. Ouvrez demo-test.html dans votre navigateur
2. Cliquez sur "Charger une image"
3. Sélectionnez une photo avec un vêtement
4. Le prompt est déjà configuré : "Changer en bleue le vêtement"
5. Cliquez sur "Transformer l'image"
6. Observez le résultat !

Option 2 : Application complète

1. Ouvrez index.html
2. Allez dans la section "Transform"
3. Uploadez votre image
4. Entrez le prompt : "Changer en bleue le vêtement"
5. Choisissez Seedream v4.5
6. Ajustez la force à 0.7
7. Générez la transformation
