## 🔧 Configuration Docker

### Dockerfile
```dockerfile
FROM nginx:alpine
COPY . /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### Taille de l'image
```
Base Alpine : ~5 MB
+ Nginx : ~2 MB
+ Application : ~3 MB
Total : ~10 MB
```

### Performance
- ⚡ Démarrage : < 1 seconde
- 🚀 Temps de réponse : < 50ms
- 💾 RAM utilisée : < 20 MB
- 🔄 Requêtes/sec : > 1000
